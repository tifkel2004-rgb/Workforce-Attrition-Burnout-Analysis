# 📊 Workforce Analytics: Attrition & Employee Burnout Dashboard

### Project Overview
This repository hosts a human-centered people analytics project exploring employee burnout, organizational health, and attrition risks. Utilizing an operational workforce dataset of 1,470 records across 35 unique variables, this project applies rigorous statistical logic to identify systemic root causes behind workforce turnover and translates those complex metrics into an interactive executive business intelligence dashboard.

### 📊 How This Applies to Workforce Analytics & Headcount Modeling
This project parses a standard human resources operations dataset of 1,470 records across 35 unique variables (such as department tiers, compensation levels, and tenure intervals). The dashboard structure functions just like enterprise workforce analytics modules. It demonstrates how I take raw employee logs, group them by demographic segments, and turn them into interactive reporting views that leadership teams can use to spot real-time retention risks.

### Core Capabilities Demonstrated
* **Executive Dashboard Architecture:** Built a dynamic, business intelligence reporting system natively within Tableau Cloud to display complex organizational health trends on a single scannable canvas.
* **Operational Segmentation:** Designed interactive filters and drop-down segmentation grids, allowing leadership teams to instantly isolate risk trends by department, tenure interval, and satisfaction metrics.
* **Root Cause & Trend Analysis:** Combined a statistical behavioral framework with data visualization to track the specific variables—such as overtime distributions and role alignment—that signal employee burnout before it impacts retention.
* **Data Visualization Best Practices:** Applied clean visual design principles (Executive KPI strips, side-by-side behavioral tracking grids, and trend lines) to eliminate reporting noise and streamline stakeholder decision-making.

### Technical Toolkit Used
* **BI Software:** Tableau Cloud / Tableau Desktop
* **Data Scale:** 1,470 Records, 35 Data Columns
* **Methodologies:** People Analytics, Trend Isolation, Corporate KPI Presentation
